## Research findings

A researcher agent reported these on 2026-11-24. "Unverified" marks a claim that no fetched source states.

| Topic | Finding |
|---|---|
| macapps.link | The site shows a Terminal command that pipes a script from `api.macapps.link` into `sh`. The script downloads from each vendor's site and runs no checksum step. The footer reads "2014-2022". |
| Competitors | Ninite is Windows only. Applite and Cork are native Homebrew front ends with no web handoff. InstallKit needs Homebrew and Terminal. The researcher found no live Mac product with a web-to-app handoff. |
| Homebrew Cask API | `https://formulae.brew.sh/api/cask.json` is about 19.5 MB. Each cask has `url`, `sha256`, `version`, `variations`, `artifacts` (with `app`, `pkg`, `installer`, `uninstall`, `zap`) and `depends_on.macos`. |
| Homebrew licence | The cask repo and the API site repo are BSD 2-Clause. No page states terms for the API data. Unverified for commercial reuse. |
| Cask counts | The number of casks with `sha256 :no_check` and the share that ship a `pkg` or `installer` are not yet computed. |
| Signing | Changing a file inside a notarized app breaks its signature. Per-user data must sit outside the signed app. Unverified from Apple's own pages. |
| Download origin | Browsers write the download URL to the `com.apple.metadata:kMDItemWhereFroms` attribute of the downloaded file. Chromium does not strip the query string. Safari's behavior and private browsing are unverified. |
| Installing a .app | `/Applications` is writable by admin users. A standard user can write only to `~/Applications`. Unverified, from forum posts. |
| Installing a .pkg | It needs root. The supported route is an `SMAppService` daemon that the user approves in System Settings. |
| Quarantine | An app that downloads files does not quarantine them by default. Settlein must set quarantine itself to keep Gatekeeper's check. |
| Removing apps | macOS 13 and later guard other apps' bundles with the App Management permission. Apple offers no API to request it. The user grants it in System Settings. |
| Mac App Store | A third-party app can open an App Store page. It cannot start the install without private or root mechanisms. |
| Cost | The Apple Developer Program costs 99 US dollars a year. Developer ID signing and notarization need it. |
