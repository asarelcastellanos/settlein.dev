Settlein plan, v1.0

Settlein is a website, a native Mac app and a catalog of 44 apps. The site lets a person tick apps, and the Mac app confirms, downloads, verifies and installs them, and later removes them. No code is written in the planning session. Building starts in a later session with step 1 of the build order.

Status: Approved 2026-11-24, building not started. Spec: spec v1.0. Grill record: 2026-11-24-settlein-v0.1.

Decisions

Each card is a decision with real options. The chosen option is marked and has a heavy border. Cards run in number order.

0001. Public product built for the owner first

  • ChosenPublic, built for the owner first
  • ConsideredOnly the owner
  • ConsideredPublic, broad from day one

WhyThe owner wants a better service than macapps.link, and the owner's own new-Mac setup gives the first catalog a concrete test.

ADR-0001

0002. The download carries the selection

  • ChosenThe download carries the selection, as Ninite does on Windows
  • ConsideredA settlein:// link that opens the app after a separate install
  • ConsideredA short code the person types into the app
  • ConsideredA checklist inside the app, with the website optional

WhyIt takes one click and no typing on a Mac that has nothing installed.

ADR-0002

0003. Curated catalog on Homebrew Cask data

  • ChosenA curated list whose download data comes from Homebrew Cask
  • ConsideredAll of Homebrew Cask with search
  • ConsideredA catalog maintained fully by hand

WhyThe owner chooses which apps appear while Homebrew's contributors keep links, versions and checksums current.

ADR-0003

0004. Uninstall only what Settlein installed

  • ChosenRemove apps Settlein installed, with their support files
  • ConsideredRemove any app on the Mac, with its support files
  • ConsideredMove the app bundle to the Trash and leave support files

WhySettlein then deletes only paths the catalog names for an app it put on the Mac.

ADR-0004

0005. Copy apps and open pkg installers

  • ChosenCopy .app bundles, and open each .pkg in Apple's Installer for the person
  • ConsideredInstall only copy-to-Applications apps
  • ConsideredInstall both unattended through a privileged helper

WhyThe catalog can hold apps such as Zoom without Settlein running any code as root during an install.

ADR-0005

0006. The website is the only catalog interface

  • ChosenThe app opens the website, and the site hands the selection back through a settlein:// link
  • ConsideredA full checklist inside the app
  • ConsideredA short code typed into the app

WhyThe app is installed by then, so the link works, and only one catalog interface exists.

ADR-0006

0007. Free and open source

  • ChosenFree and open source
  • ConsideredFree, closed source
  • ConsideredPaid

WhyAnyone can read what the installer does, and a free product avoids the open question about commercial use of Homebrew's data.

ADR-0007

0008. Swift and SwiftUI for the Mac app

  • ChosenSwift and SwiftUI
  • ConsideredTauri
  • ConsideredElectron

WhyThe security and file APIs the app needs are native Swift calls, and the download stays at a few megabytes.

ADR-0008

0009. The selection lives in the URL

  • ChosenThe page address holds the selection, for example ?apps=firefox,raycast
  • ConsideredAccounts with saved lists
  • ConsideredNo saved selection

WhyA bookmark or a pasted link restores the selection with no account and no stored data.

ADR-0009

0010. Admin password to remove pkg apps

  • ChosenRun the removal as root after one macOS admin password prompt
  • ConsideredRemove what Settlein can reach and list the rest for the person
  • ConsideredOffer no uninstall for .pkg apps

WhyThe owner wants uninstall to leave nothing behind.

ADR-0010

0011. Signature always, checksum when present

  • ChosenRequire a valid Developer ID signature and notarization for every app, and a matching checksum when Homebrew gives one
  • ConsideredRequire both for every app
  • ConsideredTrust the checksum alone

WhyThe signature check covers every app, including the ones with a fixed download link.

ADR-0011

0012. Cloudflare Pages hosting

  • ChosenCloudflare Pages
  • ConsideredGitHub Pages
  • ConsideredVercel

WhyIt serves static files and edge functions for free with no bandwidth charge, and its cookieless Web Analytics meets the analytics answer.

ADR-0012

0013. One public repository

  • ChosenOne public repository named settlein.dev under the owner's GitHub account, with an MIT licence
  • ConsideredOne private repository made public at release
  • ConsideredSeparate repositories for the site, the app and the catalog

WhyA change to the catalog format reaches the site and the app in one pull request.

ADR-0013

0014. Sparkle updates for the Settlein app

  • ChosenAutomatic updates with Sparkle
  • ConsideredA notice on launch that links to the download
  • ConsideredNo update mechanism in the first version

WhyA fix to the installer reaches every Mac without the person downloading Settlein again.

ADR-0014

0015. Settlein publishes its own catalog file

  • ChosenA scheduled job builds a small Settlein catalog file from Homebrew once a day, and the site and the app read only that file
  • ConsideredThe app and the site call Homebrew's API directly
  • ConsideredA catalog file written by hand into each release

WhyA change or outage at Homebrew then breaks one job instead of every installed app.

ADR-0015

0016. Astro for the website

  • ChosenAstro
  • ConsideredHand-written HTML, CSS and JavaScript with no build step
  • ConsideredNext.js

WhyIt renders the catalog to static HTML at build time and ships only the small script the checklist needs.

  • ConsideredUpdate installed apps

  • ChosenApple silicon, current macOS and one before. The owner's Mac runs macOS 27.2.1, so that means macOS 27 and macOS 26.
  • ConsideredIntel Macs

  • ChosenWeb analytics, privacy first, on the website only.
  • ConsideredAnalytics in the Mac app

  • ChosenSkip it and say so.
  • ConsideredInstall it again

WhyA ticked app that is already on the Mac is skipped and the app says so.

Q25. Quiet, Mac-native site

  • ChosenQuiet and Mac-native. One page, a grid of app icons grouped by category, a sticky bar with the count of ticked apps and the download button, light and dark themes that follow the system.

WhyThe owner described the site as quiet and Mac-native.

Grill record, Q25

  • ChosenAdmin users install to /Applications. Standard users install to ~/Applications.
  • ConsideredAlways /Applications
  • ConsideredAlways ~/Applications

WhyA standard user can write only to ~/Applications, while an admin user can write to /Applications.

Risks

  • The download cannot carry the selection (S1, S2). C15 fails as written. The owner then picks a fallback in a new ADR that supersedes ADR-0002. The likely fallback is a plain download followed by the settlein:// link, which costs one extra click.
  • macOS requires the App Management permission to remove an app (S8). C29 needs a new claim for a one-time step in System Settings, and the uninstall screen must guide the person through it.
  • Apple enrolment takes days. The test build and every signed build wait for it. Catalog and Website can proceed meanwhile.
  • Homebrew changes its JSON format or states terms that forbid reuse. The daily job fails or the catalog needs a new source. The site and the app keep working from the last good catalog file.
  • A catalog fact is wrong. The researcher read each cask through a summarising tool. The catalog job reads the raw JSON and must refuse an entry that breaks the rules, and QA installs every one of the 44 apps.
  • A vendor releases a new version before the daily job runs. The checksum fails and that app does not install until the next run. The app must name the reason so the person can retry later.
  • Leftover data misses paths or names a wrong one. A miss leaves files behind. A wrong path under the root step could delete system files. C31 limits deletion to listed paths, and each pkg entry's paths get a review before release.
  • A pkg install is cancelled in Apple's Installer. Settlein cannot see the outcome directly and must check for the app afterwards.
  • The Sparkle key is lost. Existing installs can never update again. The owner keeps a backup.
  • No macOS 26 machine exists. C26 is proved on macOS 27 only, and the spec must say so.
