# 0001. Public product built for the owner first

## Context and problem statement

Settlein could be a personal script or a public service that competes with macapps.link. The audience decides whether the app needs Developer ID signing, notarization and a public catalog. It also decides how much catalog work comes before the first release.

## Considered options

* Public, built for the owner first
* Only the owner
* Public, broad from day one

## Decision outcome

Chosen option: "Public, built for the owner first", because the owner wants a better service than macapps.link, and the owner's own new-Mac setup gives the first catalog a concrete test.

### Consequences

* Good, because every release gets used on a real new Mac by the owner.
* Good, because the catalog starts small enough to test every app.
* Bad, because a public Mac app needs the Apple Developer Program at 99 US dollars a year, Developer ID signing and notarization before anyone else can run it.
* Bad, because the first catalog reflects one person's taste and will miss apps other people expect.
