App structure

One WindowGroup window. A root view switches on enum Screen { pick, installing, finished, installed, unreachable }. Uninstall, Cancel and Change selection use one reusable centred panel (a ZStack overlay with a dimmed background), not .sheet. Handle the website link with .onOpenURL (custom URL scheme) and parse the app tokens from it.

Look

Light only: .preferredColorScheme(.light). System font. Accent colour #3A5BEF set as the asset catalog AccentColor. Bottom bars use .glassEffect on macOS 26 and 27. Rows 52 pt, icons 34 pt, window 900 × 620 default.

Rules to keep

Installing starts as soon as SettleIn opens (owner decision, replaces C18). Catalog only from settlein.dev (C5). Refuse unsigned, un-notarized or checksum-mismatched downloads and say why (C22, C23). Keep quarantine (C24). Send no data about the person or the Mac (C27). Delete only catalog-listed paths (C31).
