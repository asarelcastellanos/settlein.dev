Menus

Menu bar

What it shows

  • SettleIn's own menus. File, Edit and Window keep their standard items.
  • Check for Updates runs Sparkle (C33).
  • Change Selection and Cancel the Rest are enabled only while installing.

Build it in SwiftUI

  • .commands { CommandGroup(after: .appInfo) { CheckForUpdatesView(updater:) } } for Sparkle.
  • CommandMenu("Apps") with .keyboardShortcuts: ⌘N Pick Apps, ⌘1 Installed Apps, ⌘E Change Selection, ⌘. Cancel the Rest.
  • Help items open settlein.dev pages with NSWorkspace.shared.open; Report a Problem opens the GitHub issues page.
  • No Settings window: SettleIn has no preferences.

Proposal, owner decides. Menu titles and shortcuts are a proposal; the brief doesn't cover menus.
