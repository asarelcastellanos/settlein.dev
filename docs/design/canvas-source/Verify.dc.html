How SettleIn checks every app

Every app comes straight from its own developer, and SettleIn checks it before it installs. If a check fails, SettleIn refuses that app and tells you which one and why.

Developer ID signature

Every download must be signed with a valid Developer ID.

A missing or broken signature means SettleIn refuses the app.

Apple notarization

Apple must have notarized the download.

If it hasn't, SettleIn refuses it.

Checksum

When the catalog lists a SHA-256 checksum, the download must match it exactly.

These apps publish no checksum, so they rely on the signature and notarization checks:

Google ChromeSpotifyGoogle DriveAnyDesk

macOS checks again

SettleIn keeps the quarantine flag on every app it installs.

That way macOS runs its own check the first time you open each one.

Installers stay Apple's

These apps come as installer packages.

SettleIn checks them, then opens them in Apple's Installer for you to click through:

ZoomMicrosoft TeamsGoogle DriveOneDriveTailscaleTeamViewer

One source for the list

The app reads its catalog only from settlein.dev.

Clean removal

When you uninstall an app, SettleIn deletes only the files the catalog lists for it.

Removing an installer-package app asks for your admin password once.
