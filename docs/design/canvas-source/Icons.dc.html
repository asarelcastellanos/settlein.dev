SettleIn app icon

Unpacked: three white app tiles thrown out of an open white box, on the blue-violet gradient. One still icon, and one animation for the places that can move.

Still icon

Used everywhere the icon cannot move, and as the resting state of the animation.

  • Dock, Finder and LaunchpadThe app icon. macOS always shows app icons still.
  • SettleIn.dmg and the app in ApplicationsThe file icons people see before and after install.
  • Browser tabThe favicon on settlein.dev, at 32 and 16 px.
  • Website header and footerNext to the SettleIn name, once the page has loaded.
  • GitHub and link previewsThe repository avatar and the image shown when settlein.dev is shared.

Animated icon

The tiles spring out of the box one after another, 0.12 s apart. Plays once where noted; with Reduce Motion on, it shows the still icon.

  • Website header, on loadPlays once when settlein.dev opens, then rests as the still icon.
  • Disk image windowPlays as the SettleIn.dmg window appears, before the person opens the app.
  • First launchPlays once on the confirmation screen the first time SettleIn opens.
  • Done screenPlays again when every app has installed: the box is unpacked.
