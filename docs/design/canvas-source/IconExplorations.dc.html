Adding motion to the still icon

StillNo motion marks. Cleanest at small sizes.
TrailsSoft light trails from the opening to each tile, fading toward the box.
EchoesFaint copies of each tile along its path, like a long exposure.
Speed linesShort lines behind each tile, comic-style. Most energetic, busiest at 16 px.
Animated

The tiles pop out of the box

Each tile starts small inside the box, then springs up to its place one after another, holds, and fades back. macOS shows the Dock icon still, so this is for the places that can move: the website logo on load, the disk image window, the app's first launch and the Done screen. With Reduce Motion on, it shows the still icon.
